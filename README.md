# BarLoop

YouTube, 로컬 영상 또는 음원을 마디·시간 구간으로 반복하고 드럼 연습에 필요한 클릭과 템포 훈련을 브라우저에서 실행하는 React 도구입니다. 서버, 계정, 데이터베이스를 사용하지 않습니다.

## 드러머용 주요 기능

- YouTube, 로컬 영상, 로컬 음원 재생
- BPM·박자·첫 다운비트 기준 마디 자동 분할
- 마디 범위 및 A–B 시간 반복
- 음원 파형과 터치 가능한 A/B 반복 핸들
- Web Audio 기반 메트로놈, 첫 박 강세, 4분·8분·셋잇단·16분 서브디비전
- 0·1·2·4마디 카운트인
- Gap Click: 클릭 마디와 무음 마디 반복
- 반복 횟수 기준 템포 트레이너
- 반복 구간 프리셋, 메모, 목표 횟수
- 프리셋 JSON 내보내기·불러오기
- 전체 화면 드러머 연습 모드와 화면 꺼짐 방지
- 선택적 Web MIDI 패드 조작
- 휴대폰·태블릿용 큰 터치 영역, 안전 영역, 가로 모드 대응

## 개인정보와 저장 방식

로컬 미디어 파일은 `URL.createObjectURL()`로 현재 브라우저에서만 읽으며 서버로 전송하지 않습니다. BPM, 배속, 클릭 설정과 구간 프리셋은 브라우저 `localStorage`에 저장합니다. 다른 기기로 옮길 때는 구간 JSON 내보내기·불러오기를 사용합니다.

## 모바일·태블릿

- iPhone/iPad Safari와 Android Chromium 계열에서 터치 조작을 기본으로 설계했습니다.
- `연습 화면`은 Fullscreen API가 없는 브라우저에서도 화면 전체를 덮는 인앱 모드로 동작합니다.
- 화면 꺼짐 방지는 지원 브라우저에서만 켜집니다.
- Web MIDI는 브라우저 지원 여부에 따라 선택적으로 표시됩니다.
- YouTube와 로컬 파일의 재생 정책상 처음에는 사용자의 화면 터치가 필요할 수 있습니다.

## 키보드 단축키

| 키 | 기능 |
|---|---|
| `Space` | 재생 / 일시정지 |
| `←` / `→` | 5초 이전 / 다음 |
| `Shift` + `←` / `→` | 0.1초 이전 / 다음 |
| `R` | 반복 구간 처음으로 이동 |
| `L` | 반복 ON / OFF |
| `[` / `]` | 현재 위치를 A / B로 설정 |

## 권장 미디어 형식

- 영상: MP4(H.264/AAC), WebM
- 음원: MP3, WAV, M4A/AAC, OGG

MOV, HEVC/H.265, FLAC 등은 운영체제와 브라우저에 따라 재생되지 않을 수 있습니다.
